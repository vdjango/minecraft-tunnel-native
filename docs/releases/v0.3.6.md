# Minecraft Tunnel Native v0.3.6

本版包含联机节点网页反馈列表的布局修复，以及 Windows 自动化联机测试的端口分配修复。

- 问题反馈列表改为限定高度滚动，避免记录较多时页面拉得过长。
- 缩小记录行间距，长标题最多显示两行，保留搜索、状态筛选与翻页。
- 调整手机布局，并更新页面样式缓存版本。
- 修复 Windows 构建测试偶发的 UDP 端口绑定失败：为测试服务分配同时可用的 TCP、UDP 端口，保留实际 P2P、模组下载和传输验证。
- 新增测试，覆盖端口被拒绝、端口占用、资源释放以及实际 TCP、UDP 通信。
- 将 macOS ARM 构建迁移到仍受支持的 macOS 15 运行器，避免旧运行器退役影响发布；保留 macOS 14 部署目标。

提供 Linux x64、Windows x64、macOS ARM64、macOS x64 运行包，以及 Ubuntu amd64 DEB 安装包；发布流程会校验各平台产物及 SHA-256。

本版属于联机节点及原生桥，不是 Buggcraft 启动器安装包。
