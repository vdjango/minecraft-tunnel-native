# Minecraft Tunnel Native v0.3.7

官网、下载站和节点网页增加首次打开时的加载反馈，站内切换可立即显示进度并保留浏览器前进、后退和页面元信息。页面使用 Vue 接管导航，保留服务端页面供搜索引擎和未启用脚本的浏览器访问。

房间成员名称绑定到经过认证的节点账户，避免客户端提供的名称与真实账户身份不一致。保留此前的登录、问题反馈、连接诊断和节点运行时间修复。

提供 Linux x64、Windows x64、macOS ARM64、macOS x64 运行包及 Ubuntu amd64 DEB 安装包。发布流程校验各平台产物和 SHA-256 校验和后公开版本。
