# 服务精简与复用验收

2026-11-10：统一账号网页与受管节点按核心功能收敛。控制与节点保持独立进程和配置，支持同机与第三方分别部署。北京实际切换及证据见[控制部署记录](../../buggcraft-control-native/docs/10-IP部署与受管接入.md)。

## 功能范围

| 范围 | 保留 | 删除或退出当前运行路径 |
| --- | --- | --- |
| 统一账号网页 | 登录注册、邮箱验证/绑定、复制控制地址、启动器批准/刷新/撤销、退出网页 | 账号副本份数和备份策略、恢复文件下载/导入/导出、昵称/备忘编辑、安全与备份菜单、网页好友/玩家、反馈/开发者/节点管理菜单 |

| 受管节点 | 中心入网/心跳、所有权证明、健康 JSON、原生转发与诊断日志 | HTML/JS/CSS、管理员/玩家登录、账号库、联邦同步、反馈、内容缓存管理、带宽网页采样任务、首次浏览器设置 |
| 中心 C++ | 身份租期、在线、好友邀请、房间归属、地区候选、容量预留与运维 API | 不另建网页社交或游戏转发副本 |

节点仅有 GET /api/status 与 POST /.well-known/buggcraft-node-proof。/、/admin、/login、/api/account/*、/api/launcher/* 无路由，返回 404。统一网页只允许账号页和依赖资源，旧管理、联邦、反馈页面与对应入口返回 404，不重定向或转发凭据。

密码解密、签名身份、TLS、Origin、CSRF 与设备撤销继续保留。已有证书、加密账号、邮箱索引与设备仍读取原格式；旧 routing 签名继续校验完整性，但不扩散或提供修改策略接口，新账号没有 routing。删除功能不代表删除真人账号或运维灾备。

## 自建与部署边界

初始化和自建接入见[03](03-节点部署与配置.md)。origin、CA、公钥、长期 enrollment 均由配置指定，没有官方控制硬编码。切换信任域使用新持久目录/独立节点身份，不能沿用另一控制签发的 managed-node.json。

同机部署不合并权限、密钥或数据库。第三方节点仅获注册凭证和自身身份，不能获得控制 admin token。账号网页适配器目前仍为 Python，控制域和游戏转发核心为 C++；不声称整个身份服务已迁移成 C++。

中心停止时已有游戏继续转发，新授权/入场/分配/好友操作仍依赖中心。单机控制与数据库的单点限制不因网页清理消失。

## 验证入口

test_service_portal 检查最小接口、本地账号隔离和安全策略；test_service_package 检查无管理凭据配置与角色资产；test_service_browser 用真实 WebCrypto 检查注册、邮箱登录、设备批准/刷新后解锁/撤销和 390/768/1280/1920 布局；test_managed_control 拒绝旧 SSH 登录；test_managed_integration 使用真实 C++ 中心、节点、桥和 C ABI，检查好友邀请、载荷/EOF、恢复与中心失联。

前端须通过 vue-tsc、Vite 和 Vitest；方法/DOM 索引、文档链接须通过检查。截图实际查看，原始证据位于 validation-artifacts。本轮是功能精简与复用验收，不把删除菜单说成已测吞吐提升。ISA/转发结果见[真实转发报告](30-性能报告/03-20261110-游戏转发与加密指令集.md)。

本轮最终本地结果：相关 Python/浏览器/配置/打包回归 23 项通过（17.126 秒），真实中心与 CLI/C ABI 完整链路 2 项通过（13.023 秒），Vitest 31 项通过，vue-tsc/Vite、两仓清单、文档门禁和 Skill 校验通过。STUN 在个别回环端口不可用时转发仍通过，不能把仅中继测试算成 P2P 验收。

重复代码复核补充：对 web/tunnel Python 函数体做 AST 对照，对中心 src 与节点 core/bridge 的 .cpp 方法体做语法 token 对照，忽略注释/空白，筛选至少六行的方法；本轮扫描未发现完全相同方法体。该检查不覆盖所有头文件、细小片段、变量改名或语义等价，不据此承诺全仓绝无重复。实际复用决策仍以上表与调用链检查为准。
