# 联机节点 0.3.10

正式版本，适用于现有节点升级和新节点部署。

- 加入联邦时，加入方采用邀请方的资源下载加速配置，写入本机并立即生效；邀请方的配置不受影响。
- 同步包含源站地址、授权与启用状态，覆盖加入方原有设置。旧邀请需在升级后的邀请方重新生成。
- 保存失败时回滚本次加入，保留原有联邦及资源设置。
- 节点后台补齐源站生成接入邀请的路径说明，源站授权仍支持立即接入和断开。
- 可信反向代理改为明确开关，仅启用时显示网段设置；Cloudflare 另行选择，未启用时不信任其缓存网段、不请求地址列表。
- 保留已有手工反向代理网段；节点名称、地区和容量预算仍由各节点管理。
- 收录已部署的四地节点管理、容量与时钟同步改进及中文协议文档。

联邦邀请包含入网密钥和源站授权，请仅私下交给可信的节点管理员。先升级邀请方，再重新生成邀请供新节点导入。

- 统一生成文件的换行符，确保 Windows 与 Linux 校验同一份样式版本。
