# 好友短码

节点网页和启动器使用 12 位好友码，显示为 `XXXX-XXXX-XXXX`。查找不区分大小写，允许省略短横线；用户名和原有 65 位账号 ID 继续可用。

好友码由 `SHA-256("buggcraft-friend-v1:" + 完整账号 ID)` 的 Base32 编码前 12 位生成，分为三组。它是公开查找别名，不是凭据。生成不依赖节点地址，无需迁移账号或好友关系。请求、接受、邀请和签名继续使用完整账号 ID。节点验证目录签名，启动器独立计算短码核对查询结果；多条匹配返回候选列表。

节点的好友状态通过 `capabilities.friend_code` 宣告支持。启动器连接旧节点时仍复制完整账号 ID。要使用短码查找，接入节点需要更新；未更新节点不支持短码解析。
