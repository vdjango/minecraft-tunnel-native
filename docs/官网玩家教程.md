## 下载游戏与安装加载器

分类：开始游玩 · 约 3 分钟阅读 · [官网原文](https://bugg.icu/docs/help/download-game)

从选择 Minecraft 版本开始，安装原版或模组加载器，确认 Java 和内存后进入游戏。

### 先准备启动器和游戏账号

从下载站选择适合自己系统的 BUGG 启动器。首次打开后完成引导，设置游戏目录，并使用你拥有的 Minecraft 游戏账号和合法游戏文件。

已有游戏可以添加到实例管理里。一个实例对应一套游戏版本、模组和启动设置，方便把不同玩法分开。

### 选择游戏版本

1. 进入「下载」里的游戏分类。
2. 找到要玩的 Minecraft 版本，进入安装页面。
3. 填写容易辨认的实例名称，确认安装目录。

![下载页的游戏版本列表，界面示例。](https://bugg.icu/help-assets/game-versions.webp)

下载页的游戏版本列表，界面示例。

### 按玩法选择加载器

只玩原版，可以不装加载器。玩整合包或模组时，按作者要求选择 Forge、NeoForge、Fabric 或 Quilt，并核对加载器版本。

Forge 与 NeoForge 需要分别选择，不能仅凭游戏版本号相同就互换。也不要把服务端压缩包当作客户端安装。

![游戏版本与加载器安装入口，界面示例。](https://bugg.icu/help-assets/game-install.webp)

游戏版本与加载器安装入口，界面示例。

### 等待下载和安装完成

开始安装后，可以在下载任务中看进度。首次安装会准备游戏核心、依赖库和原版资源，耗时取决于文件大小、已有缓存和下载来源。

某个文件失败时，先查看任务日志里的文件名与错误。使用任务提供的继续或重试入口，不必重新删除整套游戏。

### 确认 Java 与内存，再启动

按游戏或整合包要求准备 Java。可以扫描本机已有 Java，也可以在启动器中添加或下载。

内存按整合包建议设置，并给操作系统留出空间。选择刚安装的实例启动；如有启动前检查提示，先阅读具体原因。

> 安装完成表示文件准备完成，能否正常进入游戏还取决于 Java、模组兼容性和电脑配置。

## 导入整合包与补齐文件

分类：开始游玩 · 约 3 分钟阅读 · [官网原文](https://bugg.icu/docs/help/import-modpack)

导入本地 mrpack 或常见 zip 整合包，选择独立实例，查看下载进度并处理缺失文件。

### 先确认拿到的是客户端整合包

常见的 .mrpack 和带有安装清单的 .zip 整合包可以尝试导入。普通文件夹压缩包、服务端包或再次套了一层目录的压缩包，不一定能按整合包识别。

先看作者给出的游戏版本、加载器、Java 和内存要求。

### 拖入文件，或从导入入口选择

1. 在下载页点击「导入整合包」，也可以把支持的整合包文件拖入启动器。
2. 选择独立实例和安装位置，确认识别出的 Minecraft 与加载器版本。
3. 开始安装，在下载任务中查看准备、下载、校验和安装进度。

![整合包导入入口，界面示例。](https://bugg.icu/help-assets/modpack-import.webp)

整合包导入入口，界面示例。

### 整合包为什么还要下载文件？

许多整合包只包含文件清单和配置，并没有把所有模组本体装进压缩包。导入后仍需从对应来源获取模组、游戏库和原版资源。

下载速度取决于来源与缓存。公开来源可用时直接下载，命中服务缓存时按策略取用；不是每个资源都已经存放在 BUGG 的服务器里。

### 有文件失败时怎么处理

先看失败文件和日志中的具体错误，再使用任务里的继续或补齐入口。不要仅为绕过报错删除必需模组，也不要把已经成功的文件全部清掉。

若作者要求手动获取某些文件，按作者说明放入正确位置。仍无法安装时，反馈整合包名称、版本、失败文件和日志。

### 第一次启动前再核对一次

选择新建的实例，确认 Java、内存和加载器正确。能进入主菜单后，再根据整合包说明开始游戏或联机。

> 保存原压缩包有助于再次安装，但它不一定包含实际存档。备份世界时请单独备份对应的存档目录。

## 安装模组、资源包与光影

分类：开始游玩 · 约 3 分钟阅读 · [官网原文](https://bugg.icu/docs/help/resources)

区分模组、资源包与光影，按实例、游戏版本和加载器选择资源，避免装错位置。

### 先选对要修改的实例

同一启动器可以管理多个玩法。安装资源之前，先确认目标实例：游戏版本是什么、加载器是哪一种，避免装到另一个整合包里。

### 在对应分类里查找资源

1. 打开下载页，选择模组、资源包或光影包分类。
2. 搜索项目，查看资源说明和适用版本。
3. 选择符合当前实例的文件，再下载到目标实例。

![资源分类与目标实例，界面示例。](https://bugg.icu/help-assets/resources.webp)

资源分类与目标实例，界面示例。

### 模组看版本，也看加载器

模组通常放入对应实例的 mods 目录。下载前核对 Minecraft 版本、Forge / NeoForge / Fabric / Quilt，以及项目列出的依赖模组。

不要仅因为文件名相似，就替换整合包已经指定的文件。给现成整合包加模组前，先备份配置。

### 资源包和光影还要在游戏里启用

资源包一般位于 resourcepacks 目录，进入游戏后在资源包设置里启用。光影包一般位于 shaderpacks 目录，并需要游戏中已有兼容的光影加载组件。

下载到目录只是准备文件，不代表当前游戏一定支持对应光影。具体依赖和配置以资源作者说明为准。

### 和朋友玩时如何保持一致

房间会核对需要匹配的游戏配置。涉及玩法和网络协议的模组尤其需要对齐；纯客户端显示类资源是否必须一致，要看资源本身和整合包要求。

提示不兼容时，优先使用房间同步或作者提供的客户端，不要随意删掉必需模组。

## Minecraft Java 版好友联机教程

分类：好友联机 · 约 5 分钟阅读 · [官网原文](https://bugg.icu/docs/help/minecraft)

双方登录节点，房主创建房间并开放世界，朋友核对配置后加入；一步看清完整联机顺序。

### 先看双方分别做什么

1. 双方：安装 BUGG，准备游戏，并登录同一个联机节点。
2. 房主：选择游戏实例，创建房间，进入存档并对局域网开放。
3. 朋友：使用邀请码加入，核对或同步配置，再进入游戏。

> 世界和存档在房主电脑上。节点负责发现、协商和必要的中转；房主需要保持游戏和启动器运行。

### 双方添加节点并完成登录

第一次一起玩，双方先选择同一个节点入口。节点登录用于联机授权，与 Minecraft 游戏账号的登录各有用途。

1. 进入联机大厅，从节点菜单打开「添加与管理节点」。
2. 填写 https://node.bugg.icu，点击打开浏览器登录的按钮。
3. 在网页登录账号并确认设备授权，回到大厅等待节点可用。

![添加节点与浏览器授权入口，界面示例。](https://bugg.icu/help-assets/node-login.webp)

添加节点与浏览器授权入口，界面示例。

### 房主建房并开放世界

首页选好实例，进入大厅点击「创建房间」。默认可以「先开房，稍后进入游戏」，朋友能先进入房间准备客户端。

房主启动 Minecraft 并进入存档后，按 Esc → 对局域网开放 → 开始局域网世界。确认启动器关联正确的世界，再把邀请码发给朋友。

![先建房或关联已有世界，界面示例。](https://bugg.icu/help-assets/create-room.webp)

先建房或关联已有世界，界面示例。

### 朋友加入并核对配置

大厅点击「加入房间」，粘贴邀请码。配置一致时，等世界开放后按提示进入游戏；不一致时先点「同步安装」。

多人列表没有显示房间时，可以复制启动器提供的游戏地址，在 Minecraft 的「多人游戏 → 直接连接」里粘贴。

![邀请码加入入口，示例中未填写真实邀请码。](https://bugg.icu/help-assets/join-room.webp)

邀请码加入入口，示例中未填写真实邀请码。

### 模组联机要特别核对加载器

Minecraft 版本相同仍可能不兼容。房主使用 NeoForge，朋友装成 Forge，就需要重新准备正确配置；加载器版本和必需模组也要核对。

出现不匹配提示时先查看详情和安装日志，不建议为绕过检查直接删除必需模组。

### 玩的时候保持连接，结束后再退出

网络允许时尝试 P2P，不能直连时通过节点中继。线路是否流畅取决于双方网络与节点情况。

房主退出世界后，朋友不能继续在该世界游玩；再次进入需要重新对局域网开放。最小化启动器可以，主动关闭主启动器会结束自己的联机连接。

## 房主创建房间与邀请朋友

分类：好友联机 · 约 3 分钟阅读 · [官网原文](https://bugg.icu/docs/help/create-room)

选择实例、创建准备房间、开放局域网世界，再向朋友分享邀请码。

### 确认要玩的实例与节点

先在首页选中这次使用的游戏实例，确认能正常启动。进入联机大厅，选择已授权且可用的节点。

房间配置来自创建时选择的实例，不要把另一个整合包误当作房间客户端。

### 使用「先开房，稍后进入游戏」

1. 点击「创建房间」，填写便于朋友辨认的名称。
2. 核对游戏实例，保留「先开房，稍后进入游戏」。
3. 创建房间。只和熟人玩时，保留邀请码加入；是否公开由你决定。

![创建准备房间，界面示例。](https://bugg.icu/help-assets/create-room.webp)

创建准备房间，界面示例。

### 进入存档，对局域网开放

若已经开放世界，可以在建房时选「关联已开放的世界」。发现多个世界时请明确选择，未找到时重新查找并核对游戏显示的端口。

1. 启动房间对应的 Minecraft 实例。
2. 进入自己的单人世界，按 Esc。
3. 选择「对局域网开放」，设置好游戏规则后开始局域网世界。
4. 回到启动器，确认房间已关联这个世界。

### 把邀请码发给一起玩的朋友

在房间里复制邀请码，通过可信聊天渠道发送。朋友加入后可以先准备客户端；需要邀请码的房间，即使出现在大厅，也不能只凭房间名称进入。

分享截图前遮住真实邀请码。房主也可以查看成员准备状态，确认大家是否已经准备好。

### 结束游玩与再次开房

房主退出存档会停止该世界的游戏服务。重新进入存档后，再次对局域网开放；若端口变化或检测到多个世界，按提示重新关联。

主动关闭房间或主启动器会结束联机。存档在运行世界的电脑上，重要进度请定期备份。

## 加入房间与同步客户端

分类：好友联机 · 约 3 分钟阅读 · [官网原文](https://bugg.icu/docs/help/join-room)

用邀请码加入朋友的房间，配置不一致时同步安装，再连接开放的游戏世界。

### 先取得房主的邀请码

1. 登录可用的联机节点，第一次先与房主选择同一个入口。
2. 点击「加入房间」，粘贴房主分享的邀请码。
3. 公开且允许直接加入的房间，也可从大厅列表进入。

![粘贴邀请码加入，界面示例。](https://bugg.icu/help-assets/join-room.webp)

粘贴邀请码加入，界面示例。

### 配置不一致，先同步安装

加入后查看房间要求的 Minecraft、加载器和模组。出现不匹配提示时，点击「同步安装」，选择全新下载或从已有配置补齐。

首次同步建议建立独立实例，保留原有整合包。下载和校验完成后，复核配置，再进入游戏。

![未准备好时的同步安装入口，界面示例。](https://bugg.icu/help-assets/sync-install.webp)

未准备好时的同步安装入口，界面示例。

### 同步失败时先看具体文件

公开下载来源、服务缓存、房主允许共享的文件，可能分别参与准备过程。某些文件暂不可用时，查看「安装日志」里的文件和错误，再使用界面提供的继续补齐入口。

必需模组没有准备齐前，不建议为了进入游戏直接移除；Forge 和 NeoForge 不可因为游戏版本一致就混用。

### 世界开放后进入游戏

房主尚未开放世界时，房间显示等待属于正常状态。配置准备好后可先停在主菜单，等世界开放。

按房间提示进入游戏。多人列表未出现房间时，复制启动器提供的游戏地址，通过 Minecraft 的直接连接加入。

### 断线与离开房间

网络中断后，启动器可能尝试恢复连接，但已断开的游戏连接仍可能需要重新进入。离开房间只结束自己的连接；房主退出世界后，其他人也无法继续在该世界游玩。

## 共享文件加速，让朋友更快准备客户端

分类：加速与排查 · 约 4 分钟阅读 · [官网原文](https://bugg.icu/docs/help/file-acceleration)

理解房主文件共享、清单匹配、按需上传与缓存命中，分清游戏联机和文件下载加速。

### 它加速的是文件准备

朋友加入模组房间时，通常需要准备模组、资源包等客户端文件。文件共享加速用于减少这一步的等待；游戏里的延迟还受 P2P / 中继线路和电脑性能影响。

公开来源能直接下载的文件，不必都从房主上传。关闭可选加速不等于禁止所有下载；但某个文件若只有房主持有，又没有其他来源，仍需要房主提供或另行分发。

### 房主如何开启

1. 用正确的客户端实例创建房间。
2. 在创建或房间设置的文件共享相关选项中，按提示授权共享需要的文件。具体入口以当前版本为准。
3. 保持启动器和网络连接运行，在房间里查看文件准备或共享加速状态。

> 只共享你有权分发的客户端资源。不要把账号文件、令牌、私钥或私人存档混进共享文件。

### 先提交清单，再按需处理实体文件

这不等于每个文件都会保存到云空间。最终是否缓存、保存在哪里、保留多久，由服务端策略、容量、来源可用性和授权决定；旧版客户端的流程可能不同。

1. 启动器扫描需要共享的文件信息，例如大小、哈希与已知来源。
2. 服务端根据清单检查已有缓存、来源映射和当前下载策略。
3. 命中可用公共来源或缓存的文件，使用相应下载路径；需要实体文件时，再由启动器按服务端授权上传。

### 这些状态分别说明什么

「核对／匹配来源」：正在检查清单和来源，还不能理解成已上传成功。

「等待／上传中」：仍有需要的文件待发送或确认。

「缓存命中／可用」：对应文件有可用的服务路径，但不代表整个客户端所有文件都已完成。

朋友首次安装游戏核心、依赖库和原版资源也可能花时间；这些下载与房主共享的模组文件不是同一批内容。

### 中途关房，会发生什么

关闭房间后，该房间的联机结束，尚依赖房主提供的文件也不能指望继续传完。公开来源能否继续下载、服务中已完成的临时文件是否仍可取用，要看当时任务状态和缓存有效期。

如果朋友仍在准备客户端，尽量等需要的上传完成再关闭房间。临时缓存不等于永久备份，长久保存请另行备份。

## 下载失败、进不去与联机卡顿怎么排查

分类：加速与排查 · 约 4 分钟阅读 · [官网原文](https://bugg.icu/docs/help/troubleshooting)

按下载、配置、世界开放与线路逐项检查，区分画面掉帧、游戏运算卡顿和网络问题。

### 文件下载失败

先确认失败文件和安装日志中的错误。404 表示对应地址没有取得该文件，超时与连接重置则需要结合下载来源和网络情况判断。

使用任务提供的继续、补齐或重试入口。不要因为少数文件失败就删除所有成功文件；需要手动获取的文件按作者说明处理。

### 提示加载器或模组不匹配

先核对 Minecraft、加载器名称与版本，再看必需模组。NeoForge 与 Forge 需要分别核对，不能只看游戏版本。

从正确实例建房，访客使用同步安装或作者提供的客户端。不要随意删除必需模组绕过检查。

### 进了房间却进不了世界

确认房主已进入正确存档，并执行对局域网开放。只创建准备房间，并不代表游戏世界已经运行。

确认房间关联的是当前世界。游戏多人列表没有显示时，使用启动器提供的地址直接连接。

### 先分清画面卡、世界卡还是连接卡

只有自己掉帧，先查帧率、光影、渲染距离和本机内存。多人同时遇到方块回弹、实体停顿，结合房主日志、CPU、内存和网络状态检查。

人物瞬移、连接超时或反复掉线，查看双方网络和当前 P2P / 中继状态，必要时尝试节点中继。这些表现只帮助缩小范围，不能单凭一项认定原因。

模组包的内存按作者建议设置，并给系统留出余量。内存太少和系统内存被挤满，都可能影响游玩。

### 反馈时带哪些信息

1. 启动器版本、系统、Minecraft 与加载器版本。
2. 你是房主还是访客，问题发生的大致时间和复现步骤。
3. 当前 P2P / 中继状态、完整报错文字，以及对应安装或游戏日志。

> 公开发日志前，移除密码、访问令牌、房间邀请码和其他私密信息。可以在 GitHub Issues 或节点反馈入口提交。

## Windows 10 / 11 阻止启动器运行怎么办

分类：启动器打不开 · 约 5 分钟阅读 · [官网图文教程](https://bugg.icu/docs/help/launcher-windows)

1. 从[下载站](https://download.bugg.icu/)选择 Windows。下载文件应为 `Buggcraft-windows-x64.zip` 一类的 **ZIP 压缩包**；完整解压后运行其中的 `Buggcraft.exe`。在资源管理器「查看」中开启「文件扩展名」，可分辨浏览器下载的 ZIP 与包内 EXE。
2. 如果 Windows 10 / 11 显示「Windows 已保护你的电脑」，先确认文件来自官网下载站，并核对下载页的 SHA-256；随后点击「更多信息」→「仍要运行」。受组织策略管理的设备可能没有此选项。
3. 如果 Windows 11 提示「智能应用控制已阻止此应用」，它与 SmartScreen 不是同一项保护，且没有单个应用的允许列表。先尝试重新下载最新版；如确需关闭，在自己的设备上进入「Windows 安全中心」→「应用和浏览器控制」→「智能应用控制设置」→「关闭」，阅读系统确认提示再决定。不同系统版本重新开启的条件不同，关闭会减少一层保护。
4. 双击无反应或解压报错时，重新下载并核对校验值；不要只移动 EXE 丢下同目录文件。若被安全软件隔离，检查隔离记录与来源，而不是全局关闭杀毒软件。

![SmartScreen 中文操作示意：核对来源，点「更多信息」，确认后点「仍要运行」。](https://bugg.icu/help-assets/windows-smartscreen-zh.svg)

![Windows 11 智能应用控制中文操作示意：在 Windows 安全中心进入设置并阅读关闭提示。](https://bugg.icu/help-assets/windows-smart-app-control-zh.svg)

以上是中文操作示意图，不是系统原始截图；参考：[微软：Windows 安全中心的应用和浏览器控制](https://support.microsoft.com/zh-cn/windows/security/windows-security/app-browser-control-in-the-windows-security-app)；[微软：智能应用控制常见问题](https://support.microsoft.com/zh-cn/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)。

## MacBook 提示无法打开启动器怎么办

分类：启动器打不开 · 约 4 分钟阅读 · [官网图文教程](https://bugg.icu/docs/help/launcher-macos)

1. 点击苹果菜单→「关于本机」，确认 Apple 芯片（M 系列）或 Intel；下载对应 ZIP，完整解压，将 `Buggcraft.app` 放进「应用程序」。
2. 若提示「无法验证开发者」，先尝试打开该 App，让系统出现阻止提示；然后打开「系统设置」→「隐私与安全性」，在「安全性」区域找到刚被阻止的应用，点击「仍要打开」，按提示认证。仅对确认来自官网下载的应用这样操作。
3. 若提示「已损坏」，重新下载匹配芯片的 ZIP 并核对校验值；若系统明确提示含恶意软件或会损坏电脑，不要绕过警告。受管理设备请联系管理员。
