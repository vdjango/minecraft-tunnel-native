# 反馈管理网页验收

2026-11-14。用户要求能从网站查看启动器提交的反馈和诊断日志。网页为控制主机 `/admin/feedback`，官方入口为 https://node.bugg.icu/admin/feedback；后台为原生 C++ 统一服务，转发节点继续无网页和管理凭据。

先检索现有账号页、NodeHeader、runtime/createScope 及统一服务 Service::admin 反馈接口后实现；不复活已删除的旧管理页。唯一反馈前端为 `frontend/src/feedback.ts`、`frontend/src/pages/feedback.vue`；复用共享页头、表单样式、页面取消机制与 Vite 虚拟页入口。ZIP 使用 fflate 0.8.2（MIT），不手写解压器，许可见 [依赖声明](../frontend/THIRD_PARTY_NOTICES.md)。

界面提供密钥登录、20 条分页列表、当前页筛选、问题/期望/联系方式/账号/邮件通知状态、文本和格式化 JSON 预览、原 ZIP 下载。密钥只在页面内存；刷新和退出清除，不写 URL、localStorage、sessionStorage。详情不自动加载附件，主动预览/下载时核对 SHA-256；预览每文件 1 MiB、128 项、总计 8 MiB，过大内容使用原始 ZIP。所有反馈文本由 Vue 文本插值渲染，页面异步请求归 createScope，失效回调不能覆盖当前页面。

vue-tsc、Vite、反馈状态 Vitest 两项通过。真实 Edge 连接隔离原生服务和 PostgreSQL，验证失败输入保持、登录/详情、JSON/日志预览、下载摘要、退出以及不持久化密钥。1440 与 410 宽度登录/详情/日志共六张截图逐一查看，修正了背景对比度与手机刷新按钮换行。证据在相邻控制仓 `validation-artifacts/feedback-admin-browser.json`、`feedback-admin-visual/`，只使用测试夹具数据。

已部署到官方域名，实际 TLS、登录、4 条既有记录列表及详情、退出、匿名拒绝、其他管理员路径不公开均通过。相关证据为相邻控制仓 `validation-artifacts/feedback-admin-deploy.json`、`feedback-admin-live.json`；公网截图仅未登录页。没有创建线上测试反馈或发送测试邮件，未把本地附件验证当作全部线上日志均已检查。密钥另存当前管理员的本机私密文件，不进仓库或截图。
