## 接入路径

```text
Java / C / C++ / C# / Python 启动器
                 │
                 ├── JSON-RPC 2.0 over stdio
                 └── C ABI 动态库（C、C++、C#、Python 等）
                              │
                       本机原生桥
                ┌─────────────┴─────────────┐
          SSH 控制/中继                 WebRTC P2P
                │                         DTLS/SCTP
                └──── Minecraft TCP 流 ────┘
```

跨语言可移植的边界是 JSON-RPC 方法和参数。不要让客户端依赖节点内部 JSON、SSH 用户名、心跳帧或 DataChannel 编号；这些属于组件实现细节，可能随协议版本演进。

节点开发者另读[开发指南](../节点开发指南.md)、[安全边界](../节点安全边界.md)和[联机流程图](../启动器联邦接入流程.md)。HTTP 状态、全网人数与部分失败见[网页 API](网页授权接口.md)；代理自动刷新见[部署指南](../节点部署指南.md)。仓库文档更新不会自动替换已部署节点的 `/developers` 页面。
