# 协议概览

本文说明协议涉及的组件和信任边界。服务端入口为 `web/main.py`，Python 控制业务位于 `web/tunnel/`；C++ SSH/STUN 与转发核心位于 `core/`，C++ 启动器 JSON-RPC 桥位于 `bridge/`。启动器通过 C ABI 动态库或本机进程管道传递控制参数，不实现网络联机协议。动态库入口、线程和内存所有权见 [C ABI 文档](../bridge-library.md)。

## 传输与身份

联机控制、信令与中继使用 SSH 加密连接；P2P 游戏流量使用 WebRTC DTLS/SCTP。客户端必须校验节点配置中的固定服务器公钥。玩家访问凭据与管理员网页密码分开。房主、访客、目录与联邦成员分别验证权限，只允许本房间的转发目标，不开放 shell、SFTP 或任意目标代理。

网页使用 HTTPS。接入码封装节点入口、公钥与玩家凭据，属于敏感信息；编码本身不构成加密，也不能阻止客户端得知实际连接地址。

推荐第三方启动器只实现本机桥接口。只有编写节点服务端、独立客户端或调试工具时，才需要直接使用目录、联邦或网页底层协议。
