## 维护规则

新增文档先确定唯一职责，优先扩展已有文档；需要独立文件时使用相应编号，并更新入口。编号不随临时任务变化，标题日期不代表已经上线。

协议总入口只在根目录 `PROTOCOL_STANDARD.md` 维护；好友短码已合入房间目录与身份规范；玩家教程正文只维护 `frontend/src/help/content.ts`，不保留第二份 Markdown 正文。开发规则、Skill、方法清单和 CI 路径随迁移一起更新。

实测报告留在 30；临时日志、机器配置、过期部署快照及原始测量放入 `validation-artifacts/`。2026-11-10 清理的原文和迁移表位于本地 `validation-artifacts/docs-config-20261110/`，不进入产品运行包或正式文档，禁止写入凭据。

执行 `python scripts/check_docs.py` 检查入口和引用；修改代码后运行 `python scripts/update_code_inventory.py` 及 `--check`。生成清单不能替代语义复用检查。
