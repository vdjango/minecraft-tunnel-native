| 要求 | 当前实现与边界 |
| --- | --- |
| 邮箱找回 | C++ 验证绑定邮箱、一次性验证码和恢复票据，重设密码后撤销旧授权；账号和好友保持。没有备份/恢复文件入口 |

| 登录 | 失败保留输入，成功使用昵称，不展示长账号 ID |
| 我们的时光 | 相伴天数、累计联机连接、北京时间 30 天日历、可点击的好友词云。按真实最后共同连接时间呈现久未联系伙伴，不推断“离开”；没有历史与没有好友分别显示空态 |
| 统计边界 | 已确认心跳合并多设备区间，好友共同连接按已接受关系记录。不是完整 Minecraft 进程游玩史，也不能还原启用前记录 |

| 登录设备 | 显示系统、浏览器、最近使用、当前会话和撤销；启动器设备与网页会话分别呈现，未知信息不猜测 |
| 官网与教程 | 当前启动器真实风景、蓝灰玻璃视觉；三张真实新版界面错落叠放。13 篇教程，包括玩家体验说明、联机和源站开发接入；备案号京ICP备2021040327号 |

| 源站 | 公开目录/搜索与管理分开；一套平台 Router、SiteNav/AdminNav、AdminAccess、蓝灰根主题。后台只有内容、作业、运维、接入、设置五组，原八页工作台在同一 SPA 中组合；删除独立外壳、独立登录、旧主题切换与纸卡装饰 |

## 分支、复用与并发保护

这是三个独立 Git 仓库：节点在 `main`（HEAD `9e08e180921f8f2017da7fcaf24666b184dcefd4`），统一服务在 `main`，源站在 `master`；后两者尚无初始提交。没有可以执行的跨仓库 Git merge，也没有提交、切分支、reset 或覆盖其他窗口工作。本次核对共享工作区与线上代码后按摘要集成发布；它不是一个已提交的合并版本。详见 `branch-integration.json`。

最后部署时，其他窗口正在本地改动 `mirror.py`、`mirror_control.py`、`mirror_cloud.py`、`mirror_catalog.py`、`mirror_source_management.py`。这些尚未验收的后端改动没有发布；源站最后一版从线上已验收后端复制，仅叠加网页资产。当前本地 handoff 后端对应源码包已包含这些待发改动，不能当作生产源码或直接重新部署；实际生产对应源码在各发布目录及公开 `/source.tar.gz`，精确包摘要以激活记录为准。

账号业务归控制 `browser.cpp`，活动统计归 `activity.cpp`；账号页只呈现服务端数据。注册/找回复用密码策略，计数归 DownloadStatistics；源站复用原业务 store/API 和单一导航。源站现有后端仍为 Python，没有完成源站 C++ 迁移。
