# 新版官网与账号页验收

> 历史验收记录：本页暖白紫色方案已被替代，当前蓝灰风景主题、后台统一与发布接续以第 06 号为准。

2026-11-10，公开入口为官网 `https://bugg.icu/`、下载 `https://download.bugg.icu/`、统一服务 `https://node.bugg.icu/login`。本次更新网页、账号输入行为及静态资源路由；账号适配器仍待 C++ 迁移，不代表全部交付完成。

## 实际改动与复用

按新版启动器的暖白背景、低对比边框和紫色强调色重做首页、下载页、登录注册、邮箱及设备授权页面。首页图片来自现有原生 EXE 完成初始化后的窗口，只裁掉窗口外沿。性能说明对应已有单遍摘要、扫描结果复用、受控后台任务及共用原生桥，不宣传理论 SIMD 倍率或 FPS 提升。

`accounts.js::showAccount` 只更新展示区，不再将内部 ID 写入登录框。`common.js::feedback` 对 JS 类型异常显示安全提示。保留客户端加密/签名、邮箱验证、CSRF、设备批准和撤销。

复用 `createScope/mountPage`、账号 API 和设备流程；两套构建共同调用 `build/page-assets.ts` 维护内容哈希脚本/CSS引用及过期资源清理，避免复制缓存逻辑。`service_package.identity_assets` 复用于角色打包和静态部署，按实际页面依赖选择资产。

旧节点首页、管理、网络、连接教程、开发者、网页反馈、首次设置和诊断 Vue/HTML/JS/CSS 已从产品源码、构建入口删除；旧 Portal 页面路由和渲染方法一并移除。旧后端 API 兼容夹具仍用于协议回归，不能据此重新启用节点网页。节点包不带前端；统一账号包只带账号页依赖。

## 验证与部署

- TypeScript/Vite 构建通过，Vitest 17 项通过。
- 账号、邮箱、设备批准/解锁/撤销、错误密码后重试、角色隔离和官网浏览器测试 9 项通过，使用隔离数据与真实 WebCrypto。
- 实看 390/768/1280/1920 布局及错误/设备截图，无横向溢出。线上另核对公开域名，脚本字节摘要与构建一致。
- 下载静态路由原来仅匹配 JS。增加 CSS 后仍遇 CDN 缓存 404，修正路由并更新内容哈希后重验；源站 200 不等于公开页面通过。
- 公开域名检查等待页面实际加载及登录错误返回，核对输入保留。成功账号/邮箱/设备链路在本地隔离测试，未向生产注册测试玩家。

证据见 `validation-artifacts/live-web/`、`service-web/`、`website-web/`、`web-deployment.json`。每轮线上更新在 `/tmp/bugg-web-日期时间` 保存前态及 manifest；账号库、密钥、数据库、发行缓存和资源源站未改动。临时回退材料不等同永久备份策略。
