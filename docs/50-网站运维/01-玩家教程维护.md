# 玩家教程维护

官网教程入口为 `/docs`，文章路径为 `/docs/help/文章标识`。本文件只说明维护方法，玩家正文、路由、分类和元信息统一维护在 [content.ts](../../frontend/src/help/content.ts)；不再维护 `官网玩家教程.md` 之类的第二份正文。文章数量以源数据为准，不在这里复制清单。

## 源码和职责

| 位置 | 职责 |
| --- | --- |
| `frontend/src/help/content.ts` | 标题、摘要、正文、分类、路径和示例图片引用 |
| `frontend/src/help/` | Vue 页面、目录、搜索与文章呈现；共享组件保持唯一 |
| `frontend/scripts/build-help.mjs` | 构建及预渲染教程页面，更新公开 sitemap |
| `site/docs/`、`site/help-assets/` | 构建产物，不直接手改正文 |
| `scripts/seo_submit.py` | 规范地址检查与提交，复用允许的公开路径列表 |
| `scripts/deploy_help_center.py` | 已授权的网站部署；修改源码不等于已经上线 |

## 修改流程

1. 在唯一内容源修改文章或新增稳定 slug，避免创建重复的关键词页面。
2. 复用现有 Vue 组件及品牌数据 `frontend/src/brand.json`，不另写静态 HTML 副本。
3. 执行前端测试及教程构建，检查目录、直达文章、未知路径 404、搜索、标题与 canonical。
4. 页面内容或布局改变时检查桌面/移动端实际截图；截图来自示例状态时须标明，不能充当真实联机或测速结果。
5. 网站部署和 SEO 提交仅在得到相应授权后执行，保持节点与镜像服务的独立生命周期。

文章按玩家任务组织：安装/导入/资源、建房/加入、文件准备、系统阻止启动及故障排查。协议字段在 [20-协议规范](../20-协议规范/00-协议概览.md) 维护，不复制到玩家正文；教程不承诺所有模组可下载、节点托管存档或所有网络都能直连。

## 收录与发布边界

公开内容由同一组件预渲染，正文、title、description、canonical、面包屑和 Article 数据保持一致。未知路径、搜索参数、账号页、后台和 API 不制造可索引空页。

SEO 任务接收 URL 不等于搜索引擎已经收录；凭据、服务器备份位置、临时回执及当时的部署状态不进入本维护指南。配置和任务边界见 [02-SEO 与自动提交](02-SEO与自动提交.md)。
