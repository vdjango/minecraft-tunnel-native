# 联机原生开发

同时读取工作区 [交付 Skill](../../../../.agents/skills/bugg-delivery/SKILL.md) 与 `E:/code/docs/Bugg交付清单.json`。它是产品范围、原生运行目标、网页/删除/安装/上线验收的唯一契约。下文 Python 适配器仅描述遗留复用入口，不批准继续把它作为最终产品运行依赖；迁移时保持原协议和安全契约。

默认项目位于 `E:/code/minecraft-tunnel-native`；目录变化时定位包含本项目 `AGENTS.md`、`core/`、`bridge/`、`web/tunnel/` 的根目录。以下路径相对该根目录。本 Skill 是项目源码中的唯一版本；本机技能目录可用目录链接引用它。

开工读取 `AGENTS.md`、`docs/07-代码方法与DOM清单.md`、`docs/08-生命周期与状态契约.md`、`docs/01-工程结构与开发指南.md`。性能变更读 `docs/10-跨架构性能优化.md` 与 `docs/09-性能测试与验收.md`；协议变更从 `PROTOCOL_STANDARD.md` 进入对应契约。维护清单而不是在 Skill 中复制符号目录。

文档从 `docs/00-文档总览.md` 进入，按现有编号及职责扩展，不另造同义索引。临时日志与原始测量放在 validation-artifacts，正式报告写入 30-性能报告；调整文件路径后同步引用并执行 `python scripts/check_docs.py`。转发压缩默认 off，复用节点配置与能力协商，不能把关闭额外压缩误写为关闭加密。

修改当前服务角色、账号网页或发布包前读 `docs/13-服务精简与复用验收.md`。复用 HttpSurface、AccountIssuer、Accounts、LauncherDevices 和 service_package；节点只打包无前端的 relay 角色，身份网页只跟随账号资源依赖。自建控制通过配置更换，不恢复旧节点管理/登录/联邦备份路径。历史兼容夹具不代表当前产品仍支持旧入口。

先用 `rg` 按职责搜索源码、清单、测试和调用方，再决定是否新增。编码/哈希归共享原生模块；会话状态归 Session；受管认证、社交和调度归独立 C++ 控制服务，本项目只适配协议。玩家登录仅控制主机提供，节点拒绝旧账号/directory 登录，管理员授权文件不得发到节点；职责与恢复见 docs/12。CLI、SDK 与绑定调用同一原生 Rpc/ControlClient。新方法必须写清输入、结果、失败、线程、所有者及资源释放方式，不能让不同入口拥有规则副本。

变更方法或 DOM 后运行 `python scripts/update_code_inventory.py`，完成前执行 `--check`。安装 `requirements-dev.txt` 并在 `frontend/` 运行 `npm ci` 可准备解析器。查到相似实现后，优先调用或扩展唯一所有者；新增理由与复用结果写入交付说明。生成清单不检测语义等价，仍需检查调用链和领域差异。

性能先查算法、重复 I/O、分配、队列容量与调度，再验证指令集热点。通用发布保留目标架构基线；单独编译 ISA 内核，运行时检查 CPU/OS，保留关闭路径。加密和压缩调用原库，不复制汇编、密码算法或另造转发模型。默认 Release/LTO 已有能力先核实，不能把新开关当成新算法收益。

游戏性能结论优先使用实际桥/节点载荷路径。控制面编码微基准不能充当游戏提速；加密对照必须记录实际协商 cipher，在同算法下比较 OpenSSL 硬件开关，并另测无硬件加速时的算法选择。复用现有 SSH 策略入口和转发压测，不在 SDK、启动器或节点再复制一套密码或 CPU 检测逻辑。

复用 `scripts/benchmark_cpu.py`、`scripts/benchmark.py`、`scripts/bridge_soak.py` 和现有集成测试。报告分开比较：旧代码/新代码、同代码 SIMD 开关、OpenSSL 硬件开关。至少三轮，保留范围、校验结果、构建/CPU/依赖和负载口径。微基准不能证明整条链路提速；模拟器只证明可执行与正确性，不能证明真实性能。没有 ARM/macOS 实机时明确标记缺口。

保留认证、固定公钥、握手、背压、公平调度、有界内存、哈希校验与完整 EOF。资源归属和取消遵循生命周期契约；不以取消为名等待无界同步 I/O。SDK 销毁不能与调用竞争，所有响应由原库释放。

联机验证明确记录回环、局域网、直接公网、SSH 隧道及实际 relay/P2P 路径。Windows 出现防火墙弹窗时核对程序路径，按用户当次授权处理，再验证相应网络配置文件的规则与实际数据传输；不关闭整个防火墙，不把没有出现的弹窗写成已点击。规则允许、TCP 握手和完整联机是不同证据；确认游戏握手、载荷哈希与 EOF 后才记录该路径成功。云端口受阻时保留失败及外部放行需求，不能用回环或 SSH 隧道冒充直接公网验收。

网页改动只在源码中实现，复用共享组件、导航与 `createScope`；维护 DOM/选择器配对。按项目已有构建和浏览器测试检查改动页面的真实数据、空/等待/错误状态及相关尺寸，实际查看截图后记录结论。未改 UI 不做无关网页重建。

服务器只用于用户授权的范围；测试新建独立目录和端口，不替换生产服务、关闭线上节点或修改系统性能分析权限。凭据不进入仓库、命令展示、清单与报告。普通实现和可逆验证自主完成，不因为本 Skill 添加确认步骤。
