启动器打不开 · 5 分钟阅读

Windows 10 / 11 阻止启动器运行怎么办

区分 ZIP 下载、SmartScreen 和 Windows 11 智能应用控制，按提示逐步处理启动器打不开的问题。

更新于 2026-11-11 · BUGG 项目维护者

本篇目录先确认下载与解压提示“Windows 已保护你的电脑”Windows 11 显示“智能应用控制已阻止此应用”双击没反应、缺文件或解压报错

01先确认下载与解压

  1. 从 Buggcraft 下载站选择 Windows。下载文件名应以 .zip 结尾，例如 Buggcraft-windows-x64.zip。
  2. 在“下载”文件夹中右键 ZIP，选择“全部解压缩”，再打开解压后的文件夹运行 Buggcraft.exe；不要直接在压缩包预览窗口中运行。
  3. 若浏览器只显示 Buggcraft.exe，请先打开资源管理器“查看”中的“文件扩展名”，确认它是压缩包内的文件，还是浏览器实际下载的文件。
记住这一点

下载站提供 ZIP；ZIP 内包含 Windows 启动程序 Buggcraft.exe。它们是两个不同的文件。

02提示“Windows 已保护你的电脑”

这是 Microsoft Defender SmartScreen 的提示。先确认文件确实来自 download.bugg.icu，并核对下载页提供的 SHA-256；来源不明时不要继续。

  1. 在拦截窗口中点击“更多信息”。
  2. 核对应用名称和发布者信息；确认确为自己从官网下载的文件后，点击“仍要运行”。
  3. 若没有“仍要运行”，检查是否由学校、公司或家长的安全策略管理，不要尝试绕过受管理设备的限制。
微软：Windows 安全中心的应用和浏览器控制 ↗

03Windows 11 显示“智能应用控制已阻止此应用”

这与 SmartScreen 是不同的拦截。请保留系统防护，记录弹窗原文、下载文件名和 SHA-256，联系我们核实该发行包。

  1. 从官网下载最新版本，核对 SHA-256 与文件来源。
  2. 如果仍被阻止，请把系统版本、发行版本和弹窗截图提交反馈，等待处理后的发行包。
  3. 学校或公司的受管理设备请联系管理员。
提交问题反馈 ↗微软：智能应用控制常见问题 ↗

04双击没反应、缺文件或解压报错

  1. 重新下载 ZIP，核对 SHA-256 后再解压；如果解压报错，不要继续使用损坏的文件。
  2. 确认解压目录仍保留启动器附带的文件，不要只把 EXE 单独移到别处。
  3. 如果安全软件隔离了文件，先检查隔离记录和文件来源；不要全局关闭杀毒软件。
  4. 将系统版本、弹窗原文、启动器版本和错误时间提交反馈，也可以添加微信 junsi223（优先）或加入 QQ 群 849362477 求助。

03Windows 11 显示“智能应用控制已阻止此应用”

智能应用控制与 SmartScreen 不同；它可能直接阻止未获认可的应用，也没有针对单个应用的允许列表。先从官网下载最新 ZIP 重新解压尝试。若确需运行，可在自己的设备上选择关闭此功能，但这会降低这一层保护。

  1. 打开“开始”→“Windows 安全中心”。
  2. 进入“应用和浏览器控制”→“智能应用控制设置”。
  3. 将“智能应用控制”切换为“关闭”，确认系统提示；然后重新运行已核对来源的 Buggcraft.exe。
  4. 如果开关不可用，先检查 Windows 更新及设备管理策略；受管理设备请联系管理员。

记住这一点

不同 Windows 11 版本对重新开启智能应用控制的条件不同。关闭前阅读系统确认提示，不能保证随时一键重新开启；不要仅为解决下载问题而关闭安全防护。
