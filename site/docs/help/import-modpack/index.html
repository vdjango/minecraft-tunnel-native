导入整合包与补齐文件

导入本地 mrpack 或常见 zip 整合包，选择独立实例，查看下载进度并处理缺失文件。

更新于 2026-11-11 · BUGG 项目维护者

本篇目录先确认拿到的是客户端整合包拖入文件，或从导入入口选择整合包为什么还要下载文件？有文件失败时怎么处理第一次启动前再核对一次

01先确认拿到的是客户端整合包

常见的 .mrpack 和带有安装清单的 .zip 整合包可以尝试导入。普通文件夹压缩包、服务端包或再次套了一层目录的压缩包，不一定能按整合包识别。

先看作者给出的游戏版本、加载器、Java 和内存要求。

02拖入文件，或从导入入口选择

  1. 打开顶部工具中的「导入整合包」，或把支持的本地整合包拖入启动器。
  2. 选择独立实例和安装位置，确认识别出的 Minecraft 与加载器版本。
  3. 开始安装，在下载任务中查看准备、下载、校验和安装进度。

03整合包为什么还要下载文件？

许多整合包只包含文件清单和配置，并没有把所有模组本体装进压缩包。导入后仍需从对应来源获取模组、游戏库和原版资源。

下载速度取决于来源与缓存。公开来源可用时直接下载，命中服务缓存时按策略取用；不是每个资源都已经存放在 BUGG 的服务器里。

04有文件失败时怎么处理

先看失败文件和日志中的具体错误，再使用任务里的继续或补齐入口。不要仅为绕过报错删除必需模组，也不要把已经成功的文件全部清掉。

若作者要求手动获取某些文件，按作者说明放入正确位置。仍无法安装时，反馈整合包名称、版本、失败文件和日志。

05第一次启动前再核对一次

选择新建的实例，确认 Java、内存和加载器正确。能进入主菜单后，再根据整合包说明开始游戏或联机。

记住这一点

保存原压缩包有助于再次安装，但它不一定包含实际存档。备份世界时请单独备份对应的存档目录。
