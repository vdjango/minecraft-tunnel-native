共享文件加速，让朋友更快准备客户端

理解房主文件共享、清单匹配、按需上传与缓存命中，分清游戏联机和文件下载加速。

更新于 2026-11-11 · BUGG 项目维护者

01它加速的是文件准备

朋友加入模组房间时，通常需要准备模组、资源包等客户端文件。文件共享加速用于减少这一步的等待；游戏里的延迟还受 P2P / 中继线路和电脑性能影响。

公开来源能直接下载的文件，不必都从房主上传。关闭可选加速不等于禁止所有下载；但某个文件若只有房主持有，又没有其他来源，仍需要房主提供或另行分发。

02房主如何开启

  1. 用正确的客户端实例创建房间。
  2. 在创建或房间设置的文件共享相关选项中，按提示授权共享需要的文件。具体入口以当前版本为准。
  3. 保持启动器和网络连接运行，在房间里查看文件准备或共享加速状态。
记住这一点

只共享你有权分发的客户端资源。不要把账号文件、令牌、私钥或私人存档混进共享文件。

03先提交清单，再按需处理实体文件

这不等于每个文件都会保存到云空间。最终是否缓存、保存在哪里、保留多久，由服务端策略、容量、来源可用性和授权决定；旧版客户端的流程可能不同。

  1. 启动器扫描需要共享的文件信息，例如大小、哈希与已知来源。
  2. 服务端根据清单检查已有缓存、来源映射和当前下载策略。
  3. 命中可用公共来源或缓存的文件，使用相应下载路径；需要实体文件时，再由启动器按服务端授权上传。

04这些状态分别说明什么

「核对／匹配来源」：正在检查清单和来源，还不能理解成已上传成功。

「等待／上传中」：仍有需要的文件待发送或确认。

「缓存命中／可用」：对应文件有可用的服务路径，但不代表整个客户端所有文件都已完成。

朋友首次安装游戏核心、依赖库和原版资源也可能花时间；这些下载与房主共享的模组文件不是同一批内容。

05中途关房，会发生什么

关闭房间后，该房间的联机结束，尚依赖房主提供的文件也不能指望继续传完。公开来源能否继续下载、服务中已完成的临时文件是否仍可取用，要看当时任务状态和缓存有效期。

如果朋友仍在准备客户端，尽量等需要的上传完成再关闭房间。临时缓存不等于永久备份，长久保存请另行备份。
