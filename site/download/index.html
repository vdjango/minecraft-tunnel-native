第一次使用？
  1. 01下载当前系统的启动器。
  2. 02Windows 直接运行；macOS 解压 ZIP 后打开应用；Linux 为单文件程序。
  3. 03使用你自己的 Minecraft Java 版账号和游戏文件。

Buggcraft 是 Minecraft Java 版启动器，不包含 Minecraft 游戏本体。Windows 版本可能显示 SmartScreen 提示；请确认下载来源为本官网提供的安装文件。macOS 芯片类型可在上方手动切换。

发布新版本

GitHub Actions 构建完成后，平台自动同步四个平台的安装包并缓存、校验，无需手动上传。后台选择需要审核时，版本先进入待审核；选择无需审核时，校验通过后直接发布。修改设置只影响后续入库版本。
